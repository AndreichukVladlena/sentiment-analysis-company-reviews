# Sentiment Analysis of Company Reviews

Прогноз оценки компании **от 1 до 5** по англоязычному отзыву. Данные — [соревнование Kaggle](https://www.kaggle.com/competitions/sentiment-analysis-company-reviews), метрика — MAE.

Первый этап проекта: исследование данных, наивный прогноз и TF-IDF с логистической регрессией.

## Окружение и данные

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/). Из корня проекта:

```bash
uv sync --locked --extra eda --group dev
```

Скачайте `train.csv`, `test.csv` и `sample_submission.csv` со страницы соревнования и поместите в `data/raw/`. Данные и кэши не включены в Git.

Откройте ноутбуки в Jupyter-совместимом редакторе и выберите ядро Python из `.venv`.

## Порядок чтения

1. [eda.ipynb](notebooks/eda.ipynb) — пропуски, повторы, оценки, сравнение train и test, гипотезы о признаках.
2. [baselinev2.ipynb](notebooks/baselinev2.ipynb) — медиана, текстовая модель, отдельные опыты с признаками и GridSearchCV.
3. [Решения и результаты](docs/decisions.md) — обоснования и условия экспериментов.

`company_reviews/baseline.py` содержит извлечение признаков и прогноз; `training.py` — Pipeline и подбор параметров. Ноутбук показывает сами эксперименты. Итоговая модель сохраняется локально в `data/cache/baseline.joblib`.

## Качество

После удаления 24 повторов осталось 59 976 отзывов. Все варианты ниже сравнивались на одинаковых пяти фолдах. Совпадающие после изменения регистра и пробелов тексты не разделяются между обучением и проверкой.

| Модель | Средняя MAE |
| --- | ---: |
| Постоянная медиана | 1,43781 |
| Слова и биграммы TF-IDF + Logistic Regression | 0,19008 |
| **Слова, символьные фрагменты и 13 числовых признаков** | **0,18539** |

Полный набор улучшил MAE примерно на 2,5% относительно словной модели. Наиболее сложными остаются оценки 2–4.

Признаки и параметры выбирались по тем же фолдам; независимого тестового результата или Kaggle score нет. Таблицы содержат результаты предыдущих запусков на настоящих данных. Переписанный код проверен на небольших искусственных данных, но полное обучение после упрощения не повторялось. EDA выполнена заново.
